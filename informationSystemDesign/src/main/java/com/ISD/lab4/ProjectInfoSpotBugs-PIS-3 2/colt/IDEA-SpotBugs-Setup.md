# Как запустить SpotBugs в IntelliJ IDEA

## Способ 1: Установка плагина SpotBugs (РЕКОМЕНДУЕТСЯ)

### Установка:
1. Откройте IntelliJ IDEA
2. Перейдите в **File → Settings** (Windows/Linux) или **IntelliJ IDEA → Preferences** (Mac)
3. В левом меню выберите **Plugins**
4. Перейдите на вкладку **Marketplace**
5. В поиске введите "**SpotBugs**"
6. Найдите плагин "**SpotBugs**" (от разработчика SpotBugs Team)
7. Нажмите **Install**
8. Перезапустите IDEA

### Использование плагина:
1. После перезапуска в меню появится **Analyze → SpotBugs**
2. Выберите **Analyze Project Files** или **Analyze Current File**
3. Результаты появятся в панели **SpotBugs** внизу экрана
4. Двойной клик по проблеме откроет соответствующий код

## Способ 2: Запуск SpotBugs GUI из IDEA

### Настройка External Tool:
1. В IDEA перейдите в **File → Settings → Tools → External Tools**
2. Нажмите **+** для добавления нового инструмента
3. Заполните поля:
   - **Name**: SpotBugs GUI
   - **Description**: Run SpotBugs GUI for current project
   - **Program**: `$ProjectFileDir$/run-spotbugs-gui.sh`
   - **Working directory**: `$ProjectFileDir$`
4. Нажмите **OK**

### Использование:
1. В меню IDEA выберите **Tools → External Tools → SpotBugs GUI**
2. Откроется графический интерфейс SpotBugs
3. В GUI будет уже загружен ваш JAR файл для анализа

## Способ 3: Maven интеграция

### Через Maven панель:
1. В правой панели IDEA откройте **Maven**
2. Разверните ваш проект
3. Найдите **Plugins → spotbugs**
4. Дважды кликните **spotbugs:spotbugs**

### Через терминал IDEA:
```bash
mvn compile spotbugs:spotbugs
mvn spotbugs:gui  # Запуск GUI
```

## Способ 4: Ручной запуск (уже работает)

Просто запустите в терминале:
```bash
./run-spotbugs-gui.sh
```
